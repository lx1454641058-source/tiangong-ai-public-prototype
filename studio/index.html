RETRIEVAL AUGMENTED GENERATION

分层知识库

自然语言知识帮助 Agent 理解游戏；关键数值保存在结构化、版本化的规则包中，不交给模型自由解释。

知识边界：RAG 只检索当前 gameId、targetType 和版本。库存是实时输入，美术知识不产生数值，模型不能改写守恒参数。
